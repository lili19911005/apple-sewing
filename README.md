# 裁缝宝

面向服装纸样与裁剪场景的浏览器本地转换工具。

## 已实现

- 多份 PDF 拼合为单张大画布，可设置每行页数与页面间距
- 多份 PDF 按上传顺序合并
- PDF 线稿提取并导出 HPGL/PLT
- PDF 页面逐毫米调整横向、纵向重叠，支持拖拽排序和统一裁边
- 沿真人款式图中的衣服轮廓建立选区，再生成保留褶皱明暗的布料效果预览
- 批量导入布料图片，记录长度、材质和来源，并复用到效果图工具
- 免费注册、登录与本地登录状态保存
- 桌面端与移动端响应式界面

文件转换全部在浏览器内完成，不会上传到服务器。

## 本地运行

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
npm run preview
```

## 投影校准

- 正投时使用「保持矩形」，避免小参考纸上的四角误差引入梯形变形；斜投时切换「四角梯形校正」。
- 使用 10 × 10 cm 纸张时，先点击对应预设。用卷尺测量四个十字中心围成的投影框，在「按实测尺寸修正」输入实际宽高并修正比例，再次测量验证。
- 选择角点后，可用微调按钮或聚焦微调区域后的方向键按 0.1 / 0.5 / 1 px 调整；Shift + 拖动为十分之一速度。
- 小纸只适合初校，建议以 30–50 cm 的已知距离复测四边和对角线。保持投影仪位置、分辨率与浏览器缩放不变。
- 投影视图固定在窗口内，使用全屏按钮切换全屏，拖动画面移动纸样；滚轮不会带走投影视图。返回校准后恢复页面滚动。

## 纸样库本地保存

- PDF、纸样名称、尺码、分类和缩略图统一保存在 IndexedDB。导入文件与资料在同一事务中保存，保存完成后才显示成功；批量导入中途失败不会丢失之前已保存的项目。
- 启动时自动迁移旧版 localStorage 列表，并扫描旧数据库中缺少列表资料的 PDF，重建可恢复的记录。旧列表仅在迁移成功后移除。
- 网站会申请浏览器的持久存储保护；是否批准由浏览器决定。修改保存失败时会提示并提供重试，不会继续显示已保存。
- 请在同一浏览器固定使用 `http://localhost:5173/`。`localhost`、`127.0.0.1`、不同端口和不同浏览器的资料互不相通；开发服务器固定端口，端口被占用时不会自动改用另一个端口。
- 刷新、关闭网页或重启开发服务器不需要重新导入。清除网站数据、使用无痕模式或更换设备仍可能导致资料不可用，请通过「导出本地数据」保留备份，并用「导入迁移包」恢复。已经被浏览器彻底清除的 PDF 无法由网站恢复。

存储与校准回归测试：`npm test`（Node.js 22.18+）。

## 上线前建议

当前账户与布料库使用 `localStorage`，适合产品原型和本地部署。布料图片会压缩后保存，但仍受浏览器本地存储容量限制。正式上线时建议接入 Supabase、Clerk 或自有 API，并把布料图片迁移到对象存储。

布料效果图目前采用本地轮廓选区、纹理替换与明暗混合。复杂真人照片需要先沿可见衣服边缘设置轮廓点；如果需要全自动识别衣服、处理头发遮挡和姿态变化，建议后续接入服装分割与虚拟试衣模型服务。

PDF 转 PLT 目前采用浏览器内线稿提取。正式商用前应使用目标客户的真实纸样文件建立精度与兼容性测试集。
